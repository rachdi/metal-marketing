📖 Guide d'Installation
Comment obtenir toutes vos clés API gratuitement — étape par étape
📧
Brevo — Email & SMS GRATUIT
300 emails/jour gratuits · SMS à l'unité · Aucune CB requise
1
Créer un compte Brevo
Allez sur brevo.com → Inscription gratuite avec votre email [email protected] · Vérifiez votre email
2
Obtenir votre clé API
Connectez-vous → Cliquez sur votre nom en haut à droite → SMTP & API → Onglet Clés API → Créer une nouvelle clé API v3 → Copiez la clé qui commence par xkeysib-
3
Vérifier votre domaine expéditeur
Brevo → Expéditeurs, domaines et adresses IP → Ajouter [email protected] → Vérifier (améliore la délivrabilité)
4
Coller dans ⚙️ Configuration
Retournez dans la page Configuration, collez votre clé, cliquez "Tester la connexion Brevo" · Vous verrez votre plan et quota s'afficher
📘
Facebook Graph API GRATUIT
Publication automatique sur votre Page Facebook Américafer
1
Créer une Page Facebook "Américafer Toulouse"
Facebook.com → Pages → Créer une page → Nom : "Américafer Toulouse" → Catégorie : "Recyclage" ou "Récupération"
2
Créer une App Facebook Developer
Allez sur developers.facebook.com/apps → Créer une app → Type : Business → Nom : "Américafer Marketing"
3
Obtenir le Page Access Token
Dans votre App → Graph API Explorer → Sélectionnez votre App → Sélectionnez votre Page dans le menu → Activez les permissions pages_manage_posts et pages_read_engagement → Générer le token
4
Token permanent (recommandé)
Le token expire en 60 jours par défaut. Pour un token permanent : Access Token Debugger → Collez votre token → Étendre le token d'accès
5
Trouver votre Page ID
Dans Graph Explorer → entrez /me/accounts → vous verrez votre Page avec son ID à 15 chiffres. Collez-le dans Configuration.
📸
Instagram Graph API GRATUIT
Requiert compte Instagram Pro + Page Facebook liée
1
Passer en compte Pro
Instagram → Paramètres → Compte → Passer en compte professionnel → Catégorie : Recyclage → Lier à votre Page Facebook Américafer
2
Trouver l'Instagram Business Account ID
Dans Graph Explorer avec votre token FB → Requête : /{votre-page-id}?fields=instagram_business_account → Copiez l'ID affiché (commence par 178...)
3
Entrer dans ⚙️ Configuration
Le token Facebook est réutilisé pour Instagram. Il vous faut uniquement l'Instagram User ID dans la config.
💼
LinkedIn API GRATUIT
Publication sur votre Page Entreprise LinkedIn
1
Créer une App LinkedIn
linkedin.com/developers/apps/new → Liez votre Page LinkedIn Américafer → Produits : Share on LinkedIn + Marketing Developer Platform
2
Générer un Access Token
Dans votre App → onglet Auth → OAuth 2.0 tools → Scopes : w_member_social et r_organization_social → Générez le token
3
URN Organisation
Format : urn:li:organization:XXXXXXXX → Trouvable dans votre App LinkedIn → Settings → Company
